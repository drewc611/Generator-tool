Route code lookup

Every delivery point in the Republic of Meridia belongs to exactly one sorting district, and every sorting district publishes exactly one route code, which is the five character string the sorting machines read first, and because the machines read it first the code must appear on the lowest line of the address block, printed without punctuation, without adjacent decoration, and without any other marking within one character width on either side, since a smudge or a stamp in that window is read as part of the code and sends the parcel to whichever district the damaged string happens to name, which is rarely the right one and never the fast one.

An official service of the fictional Republic of Meridia. Help
